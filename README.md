# jseverino.com-legacy

> Predecessor repo. The current public site is at [`joeseverino/jseverino.com`](https://github.com/joeseverino/jseverino.com).

A static mirror of the WordPress-era `jseverino.com`, deployed to Cloudflare Pages at [`static.jseverino.com`](https://static.jseverino.com). This repo's job was to prove Cloudflare Pages could serve the existing URL structure, layout, and SEO surface before committing to a full migration off WordPress.

```
WordPress origin  ─►  this repo (wp-static mirror)  ─►  Cloudflare Pages → static.jseverino.com
                              │
                              └── proved the case; site then moved to the Astro build at
                                  joeseverino/jseverino.com
```

## Role it played

The mirror answered the questions that needed real numbers before committing to a rebuild:

- Could Cloudflare Pages serve the existing URL structure without breaking SEO or layout?
- Which WordPress-era features had to be replaced (security plugins, contact form, dynamic feeds)?
- How much operational burden disappears once there is no origin to host, patch, or harden?

Once those answers were in, the public site moved to a vault-authored Astro build and this repo retired.

## What's in it

- `public/` — the static mirror as deployed to `static.jseverino.com`, regenerated by `scripts/mirror.sh`.
- `public/_headers` and `public/_redirects` — Cloudflare Pages config, preserved across re-mirrors.
- `scripts/mirror.sh` — wraps the [`wp-static`](https://github.com/joeseverino/tools) CLI: wipes `public/`, re-mirrors `https://jseverino.com/`, cleans WP URL artifacts, restores Cloudflare config, and applies mirror-only fixes.

## Status

No active development. Preserved as a snapshot of the migration path.

For the current site, see [`joeseverino/jseverino.com`](https://github.com/joeseverino/jseverino.com).
